Como deve ser o arquivo .json?

Uma lista questions em que cada questão tem enunciado, opções e a resposta correta (escrita igual a uma das opções). O topic é opcional. A ordem das questões e das opções é embaralhada na hora da prova.

{
  "title": "Matemática – Bimestre 1",
  "questions": [
    {
      "question": "Quanto é 2 + 3?",
      "options": ["4", "5", "6", "7"],
      "correctAnswer": "5",
      "topic": "Adição"
    }
  ]
}
